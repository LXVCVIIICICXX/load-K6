Прогоны стенда
Удаление стирает папку прогона целиком: отчёт, сводку и сырой поток k6. Восстановить нечем.
Новая запись
Откроется настоящий браузер — пройдите сценарий руками и нажмите «Остановить». Пишется всё: точное время каждого запроса, паузы между ними и признак «взято из кэша». Basic-авторизация стенда подставляется из вкладки «Настройки», раздел «Фронт стенда».
Записи браузера
Отчёты по HAR-записям реальных сессий: сколько запросов снял кэш, сколько дошло до бэка, во что каждый обошёлся в базе. Считаются по файлам из папки har/ — сюда попадают и записи отсюда, и положенные вручную из DevTools. Сверка с Telescope необязательна: без неё отчёт соберётся, только без раздела «Браузер против бэка».
Профили пользователей
Выключенный профиль не попадёт ни в один тест; выключенная роль убирает из прогонов всю свою группу. Вес задаёт долю внутри роли: при 100 : 10 : 10 первый профиль получит 83% трафика своей роли. Пароли лежат в открытом виде в users.json — это тестовый стенд, а не боевая система.
Роли
Код роли — он же префикс переменных: student даёт STUDENT_EMAIL и STUDENT_PASS, их берёт creds('student') в сценарии. Пишется латиницей. Тем же кодом помечены запросы в requests.json. Переименование кода переносит на новый и все профили роли.
Всё, что введено здесь, лежит только на этой машине — в secrets.json с правами 0600. Файл закрыт в .gitignore и в репозиторий не уходит. Обратно на страницу пароли не отдаются: заполненное поле показано как «задан», а пустое поле при сохранении означает «оставить как есть», а не «стереть». Тест сам решает, нужен ли ему раздел: незаполненный просто не используется.
Спецификация API
Swagger или OpenAPI стенда — файл .json (.yaml — только если в системе стоит PyYAML). Файлы лежат в каталоге api/ рядом с кодом и в репозиторий не уходят: спецификация — это карта чужого стенда. Отсюда морда берёт список запросов для теста «разгон одного запроса»; пока файла нет, список короткий и вписан в код. Спецификаций может быть несколько — запросы сложатся.

Список сценариев
Собранные из записей сценарии. «Скрыть» убирает сценарий из списка тестов, но оставляет файл — так его можно вернуть. «Удалить» стирает сценарий и его карту запросов; сама запись остаётся, и собрать сценарий заново можно в любой момент.
